# La Pobreza en Colombia (DANE 2025) — Presentación Cinematográfica

1. Instala dependencias con `npm install`.
2. Inicia el servidor de desarrollo con `npm run dev`.
3. Abre `http://localhost:5173/` en tu navegador.
4. Usa las flechas `←` / `→` o la `Barra Espaciadora` para navegar entre las 11 secciones cinematográficas.
5. Presiona la tecla `F` para activar o desactivar el modo pantalla completa.
